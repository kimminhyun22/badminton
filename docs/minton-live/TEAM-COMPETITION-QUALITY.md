# 팀전 품질 v4 — 2026-10-09

## 적용 범위

팀전 품질 표시와 기존 대진 후보 내 선택에 같은 순수 평가 함수 `js/team-competition.js`를 사용한다. 자유 대진 및 민턴LIVE의 평가/생성은 유지한다. 이미 게시된 경기·실력 점수·명부·수동 팀 배정을 자동으로 변경하지 않는다.

팀 구성을 통째로 바꾸는 실험은 동일 탐색 예산에서 일관된 개선을 보이지 않아 제품 생성 경로에 연결하지 않았다. 분포 보정 함수는 격리 시뮬레이션과 회귀 검증용이며 앱에서 자동 팀 재배정에 사용하지 않는다.

## 배점과 의미

경기 접전·실력 격차30 + 팀 실력 분포10 + 전체 대진 우세 균형10 + 출전 공정성20 + 다양성20 + 휴식10 = 100점.

- 경기 평가: 기존 합산/파트너 보정 격차의 평균75%와 최악20% 꼬리25%를 함께 계산한다. 이 손실75%와 연속적인 파트너 보정 격차 손실25%를 반영한다.
- 분포: 팀 평균45%, 0/20/50/80/100% 분위 차이40%, 성별 평균 차이15%. 인원 차이에 따른 기존 평균 보너스를 이 항목에 다시 더하지 않는다.
- 전체 균형: 경기당 부호 있는 평균 격차와 완만한 방향 지표 `x/(|x|+0.2)`를 반씩 평가한다. 파트너 보정값은 기존 정책 `합−0.35×파트너 차이`다.
- 접전 임계값0.15/0.20/0.25/0.30은 별도 진단이며 경계에서 총점이 갑자기 오르는 보상을 만들지 않는다. 대표0.20의 접전 수와 예상 우세 수를 표시한다.
- 출전·다양성·휴식은 기존 평가를 유지한다. 기존 안전 문제는 높은 총점으로 상쇄하지 않는다.

점수는 운영 정책 진단이다. 계수/가중치가 실전 승률로 검증됐다는 뜻이나 정확도 백분율이 아니다. v3 점수와 v4 점수는 그대로 증감 비교하지 않고 같은 버전으로 재평가한다. 내부 v3 평가값은 기존 보호 조건 검증을 위해 보존하며, 화면/임원 요약의 `scoreVersion`은4다.

## 후보 선택 보호 조건

기존 최종 후보를 기준으로 보관한다. 새 평가로 더 높아도 다음을 모두 통과해야 채택한다.

- 구성·종목 오류, 미달/추가 출전, 심한/주의 불균형, 파트너 비대칭, 최악 휴식 부담, 파트너 반복, 연속 출전을 늘리지 않는다.
- 기존 총점과 출전·다양성·휴식 항목을 낮추지 않는다.
- 평균 합산/보정 격차와 평균 파트너 보정 격차 증가는0.05까지. 최대 격차는 기존+0.2와1.5 중 작은 한도까지(기존1.5 초과이면 증가 금지).
- 대표/여러 임계값의 양쪽 우세 수 차이와 경기당 순격차를 늘리지 않는다. 접전 감소는2경기 이내다.
- 상대 최다 반복과3회 초과 반복도 늘리지 않는다.

조건을 충족하는 후보가 없으면 기존 후보를 유지한다. 탐색 횟수를 줄여 보정 후보로 바꾸지 않는다. 팀 선수와 고정 파트너는 기존 생성·후처리의 보호를 계속 적용한다.

# 민턴LIVE 감리 기록

역할: 코덱스 = 생산(만들고 배포). 클로드 = 감리(교차 모델 검토). 같은 모델은 자기 사각을 못 본다 — 검사기는 아는 결함만 센다.

## 언제 감리하나
- 2026-09-26 v1.10.725 감리 요청: 공용 공유 링크·명부 ID별 응답 등록/개인 토큰 경계. 이름 선점/타 기기 덮어쓰기 차단·개인별 동시 응답 보존·기존 개별 응답 호환 및 중복 참여 안내 감리 요청. 전체123/123, Firebase9개 배포 및 독립 브라우저 2개 실API 응답/수정/마감 확인. 이름 선택은 본인 인증이 아니며 기기 저장소 분실 복구 미지원.
- 2026-09-26 v1.10.721 감리 요청: 보정 근거 응답 확장·실제 명부와 제안 비교로 반영 완료 표시. 수치 계산/승인 기준 불변. 원본 응답 보존·응답자 비공개 경계·레거시 연령 정규화 후 적용 판정 감리 요청.
- 2026-09-25 v1.10.719 감리 요청: 개인 검증 함수 분리·퀴즈 정보 누락회원 표시/확인 후 일부 시작. 서버 검증 강도 불변, 명부 원본 불변, 필터된 스냅샷과 적용 대상 대응 감리 요청. 전체121/121 통과.
- 2026-09-24 v1.10.717 감리 요청: 분기 점검일 서버 트랜잭션 저장·90일 앱 알림·클럽별 즉시 퀴즈. 중복 응답으로 점검일 연장 불가, 기존 권한/보정 승인 경로 불변. Functions 배포와 합성 클럽 실API 검증 완료. 기기 보관 이력 및 만료 후 알림 경계 감리 요청.
- 2026-09-24 v1.10.716 감리 요청: 개인 실력 미세조정 서버 콜러블 신설·비공개 컬렉션·판단자별 공유 토큰·임시 추천 기준·명부 편집창 확인 연결. Firebase functions 배포 포함, DB 규칙 불변. 응답자의 개인정보 노출 범위와 희소 비교에서의 추천 안정성 감리 필요. 검증 근거는 WORKLOG 참조.
- 2026-09-24 v1.10.712 감리 요청: 명부5단계 보정 level 보존, 등록선수 프로필 전파 및 지각 후보 지문 변경. 서버 변경 없음. 119/119·60조합 계산 일치·양쪽 UI/CSV 왕복 검증. 실세션 임원 동시운영 검증은 미실시.
- 2026-09-24 v1.10.701 감리 요청: 팀전 시작 전 도우미 선택을 신규 LIVE 게시에 전달, 재접속 시 서버 권한 우선. 운동 종료 결과 유지·새 운동 전 자동 보관. 서버 변경 없음, 전체 111/111 통과. 실배포 검증 결과는 WORKLOG 참조.
- **필수**: functions 배포 / 새 명령 종류 / 관리자 추종·게시 경로 변경 / 실전 전날 배포.
- **정기**: 그 밖의 배포 5건당 1건(시작값).
- **완화**: 연속 3회 0건이면 10건당 1건, 연속 5회 0건이면 필수만. 결함이 다시 나오면 원래대로. 0건 감사도 기록한다 — 완화의 근거다.

## 약속
- 코덱스는 해당 작업을 마치면 아래 표에 「감리 요청」 줄을 남기고 다음 일을 계속한다. 감리를 기다리며 멈추지 않는다.
- 운영자가 클로드에게 넘기면, 클로드는 그 커밋 범위를 검토하고 결과를 같은 줄에 채운다.
- 지적은 기계로 잡을 수 있으면 테스트로 옮기고, 낡은 코드에서 그 테스트가 깨지는지 확인한다. 판단·취향이면 `DECISIONS.md` 나 `PITFALLS.md` 로 옮긴다.

# 클럽 내 개인 보정 분리 — 2026-10-09

사용자 확정: 개인 실력 보정은 해당 클럽 안의 경기 밸런스를 맞추는 용도다. 다른 클럽 응답/점수/보정을 합치거나 같은 사람이라는 이유로 전이하지 않는다. 같은 클럽의 동급 비교와 가까운 급수 교차 비교는 계속 사용한다.

현재 공개1.10.781과 일치하는 c0113fa 기반 격리 후보에서 구현했다. 기존 dirty 로컬758 작업본을 덮어쓰지 않았으며 운영 미배포다. 기존 자료 마이그레이션/실응답 제출/운영 점수 변경/일괄 재계산/규칙 변경은 하지 않았다.

- 신설 평가의 서버 기록/응답에 clubId를 붙인다. 같은 평가에 다른 클럽ID로 기준 명부를 전달하면 거절한다. 기존 평가에는 ID를 쓰거나 추정하지 않으며 기존 링크를 유지한다.
- 로컬 적용/되돌리기는 기존 clubId별 클럽 객체 안에서만 수행한다. 기준 재조회에도 평가의 로컬 클럽ID와 명부ID 일치를 요구한다. 이름이 같아도 다른 클럽 명부를 기준으로 삼지 않는다.
- 팀전 및 민턴LIVE 명부 추종을 공통 클럽 식별자/소속 resolver로 제한한다. 원래 클럽/선수를 찾지 못해도 다른 클럽의 동명 선수로 대체하지 않는다. 소속이 없는 옛 자료가 여러 명부와 겹치면 추정하지 않고 유지한다. 명확한 옛 소속명과 단일 회원ID 대응은 지원한다.
- 참가자 가져오기와 모드 전환/저장/대진 프로필에 클럽ID를 함께 보존한다. 가져오기에서 빠졌던 소속명/회원ID도 유지한다. 같은 클럽의 숫자 보정만 기존 경기 계산에 전달한다.
- 관리자는 클럽 내 실력 평가라는 제목을 보고 해당 명부에만 저장한다. 질문/응답은 평가ID별로 읽고 계산하며 별도 클럽의 동일 p0/p1 질문ID를 합산하지 않는다.

# 팀전 품질 점수 v2

적용 버전: 1.10.750. 점수는 대진 편성 평가이며 승률이 아니다. 기존 v1 점수와 직접 비교하지 않는다. 개인 실력·나이·성별·파트너 보정0.35는 변경하지 않았다.

## 합계

- 실력 균형50 + 출전 공정성20 + 다양성20 + 휴식10. 각 항목을 정수 반올림한 뒤 합산한다.
- 팀 나누기는 실력 균형 안에 포함. 설정 준수와 일정 효율은 참고/필수 검사이며 별도 가산하지 않는다.
- 구성 오류·심각한 실력차·회피 가능한 출전 미달은 총점과 무관하게 필수 확인. S 등급의 명칭은 완벽이 아닌 매우 우수.

## 실력 균형

경기별 손실 = clamp((보정 실력차 - 0.25) / (2 - 0.25), 0, 1).
보정 실력차는 기존의 원 합산차/파트너 보정차 중 큰 값이다.
경기 품질 = 1 - (평균 손실 * 0.75 + 최악20% 손실 * 0.25).
최악20% 경계 경기에는 부분 가중치를 줘서 동일 분포의 경기 수만 늘려도 평가가 바뀌지 않는다.

- 자유대진: 경기 품질 * 50.
- 청홍: 경기 품질 * 40 + 팀 배정 품질 * 10.
- 팀 배정 손실은 기존 배정 감사 손실과 남녀별 평균 차 손실 중 큰 값이다. 남녀별 차에도 기존 인원 보정 목표를 반영한다. 0.1 이하는 허용, 1.0 이상은 배정 영역 손실100%로 정규화한다.
- 파트너 비대칭·평균·최대·주의·심각 건수를 각각 누적 감점하지 않는다. 최악 경기와 심각 기준 위반은 따로 표시하고 후보 선택에서도 우선 확인한다.

## 공정성·다양성·휴식

- 공정성 손실은 목표 슬롯 대비 회피 가능한 미달*4, 초과*2, 출전 목표 달성률 표준편차 중 최댓값. 구조상 최소 초과/조정은 기존 슬롯 분석대로 제외한다. 목표0인 선수는 달성률 분모에서 제외한다.
- 다양성은 파트너만 반복한 경우0.5, 같은4명 중 완전동일이 아닌 반복1, 완전동일 반복1.5의 배타적 단계로 집계하고 전체 경기 수로 정규화한다. 비율0.5에서 다양성0점이다. 3회/4회 반복을 별도로 중복 감점하지 않는다.
- 조합 하한은 청홍 소속과 종목 성별을 고려한다. 고정 파트너의 직접 반복은 제외한다. 모든 고정 파트너·급수·라운드 가용성의 결합까지 정확히 푸는 완전한 불가피성 증명은 아니다. 미확정 제약을 추측하여 감점 면제하지 않는다.
- 휴식은 기존 회피 가능한 연속 출전 비율에 따라 10점에서 감점한다. 인원 부족으로 불가피한 연속 출전은 제외한다.

## 검증

- 완전 균형100점, 네 항목 합계 일치, 불균형 증가에 점수 비상승,10경기/100경기 동일 불균형 비율 동일 점수, 구성/심각 오류 별도 경고.
- 청홍 각2명뿐인4경기는 대안 없는 반복/연속 출전으로 다양성과 휴식 만점 유지.
- 기존 반복 개선 검사는 새 최악구간 지표의 영향을 분리하기 위해 동일급수 복제 구성으로 검사. 다른 급수의 원 재현 구성은 별도 전체 후처리 검사로 유지한다.
- 개인목표·완료·미실시·고정 파트너 보호, 점수 가중치 훼손 검출, 전체 회귀 및 모바일 합계 확인.
- 민턴LIVE의 실시간 대기/서버 배정 점수는 이번 고정 일정 평가 개편 대상이 아니다. 공통 개인 실력과 파트너 보정식은 그대로 공유한다.

## 2026-09-14 · 1.10.665 · 당일 명부·게임 세팅 임원 완전 위임 (정적 + functions)
- 요청: 정식 클럽 임원이 명부 불러오기부터 코트·진행 중 경기·대진 게시까지 맡아, 시스템 관리자 없이 당일 운영을 시작할 것.
- 새 명령 `official-roster-setup`: 정식 임원이 같은 회원 링크의 명부 시트에서 여러 후보를 `현장 참가`·`도착 전`으로 한 번에 등록한다. 화면은 후보 키와 상태만 보내고 서버가 `arrivalCandidates`의 이름·급수·성별·임원 자격을 다시 읽는다. 누락·타 클럽·중복·100명 초과가 하나라도 있으면 전체를 거절한다.
- 사전 연결: 운영 시작 전에는 도착 전 상태의 정식 임원도 클레임과 명부 설정을 할 수 있다. 임시 도우미는 불가하다. 본인을 현장 참가로 등록하면 코트 수 변경·진행 중 코트 등록·대진 게시 등 기존 임원 운영 기능이 그대로 열린다. 클레임 때 옛 상시 세션에도 `officialRosterSetupV1`을 보강한다.
- 관리자 역할: 클럽 전체 명부 편집·정식 임원 지정·최초 상시 링크 기반과 예외 복구만 남겼다. 일상 운영은 임원이 전담하고, 열린 관리자 화면은 서버 revision을 따라가는 추종자다.
- 검증: 전체 `tests: 97/97 통과 · functions 문법 8개 · 실패 0 · 29s`. 신규 회귀에서 정상 3명 일괄 등록, 서버 명부 프로필 신뢰, 도착 전 등록, 잘못된/누락/타 클럽/중복 후보의 원자적 거절, 도우미 거절, 도착 전 정식 임원 클레임·세팅, 화면·관리자 라우팅·능력 표시를 확인했다. 정식 임원 게이트를 제거한 훼손 사본은 예상대로 실패했다.
- 배포: `firebase deploy --only functions --project kokmatch-23b31` 성공(Functions 7개), 코드 커밋 `e9c552a`를 `main`에 푸시. GitHub Pages 실제 화면 `1.10.665` 확인. `database.rules.json`은 변경·배포하지 않았다.
- 실배포 E2E: 버리는 세션 `DL3TR7JY`에서 도착 전 `E2E임원`이 연결 → 가명 6명 일괄 현장 등록 → 코트 3→1 → 대진 게시 → 첫 경기 자동 투입. 서버 revision 3, 명령 장부 `official-roster-setup`·`official-settings-update`·`official-operation-start`, 관리자 현장 6명·진행 1경기와 모두 일치했다. 종료 후 `/live/checkin_DL3TR7JY`와 `/liveArchive/checkin_DL3TR7JY`가 모두 `null`임을 재조회했다.
- 남은 경계: 클럽 전체 명부 편집·정식 임원 지정·최초 상시 링크 생성은 시스템 기반 권한이다. 임시 도우미는 당일 명부 전체 설정 없이 운영 시작 뒤 현장 지원만 한다.

## 2026-09-14 · 1.10.661–662 · 매주 롤오버 (정적 + functions)
- 요청: 관리자가 매주 게시하지 않아도 같은 링크로 다음 운동일을 열 것.
- 새 명령 `official-session-rollover`(엔진 `applySessionRollover`). 조건: 게시됨·게시 뒤 4시간·4시간 안 된 진행 경기 없음·대기표 없음. 4시간 넘은 미종료 코트는 「미종료」로 접는다. 요약은 세션 `archive`(최근 4), 전문은 콜러블이 `liveArchive/checkin_<ID>/<at>` 에 쓴다. 명단은 유지, 전원 도착 전, 누른 임원만 현장, 도우미 해제, 일시정지 해제, 게시 표시 끔.
- 상시 창 30일: 대진 게시·롤오버·클레임마다 세션·초대 만료를 다시 민다.
- 지난주 「종료」로 남은 클럽 임원이 보낼 수 있게 상태 게이트 예외를 **래퍼와 엔진 두 곳**에 넣었다.
- 관리자 추종: 롤오버는 재생하지 않고 채택한다(`session/rolloverAt` 리스너·동기화 pull·수동 맞추기 → `_dailyMaybeAdoptRollover`). 관리자가 서버를 되돌리던 다섯 가지를 고쳤다(PITFALLS 2).
- 검증: 엔진 12 케이스 + 래퍼 1 + 클레임 1 + 정적 핀 30여 개, 훼손 시험 12종. 실배포 E2E 2회(버리는 세션, 정리 완료).
- 남은 것: 일괄 도착 등록, 회원 자가 도착(운영자 확인), 빈 스냅샷 경합 관측 — `BACKLOG.md`.

## 2026-09-13 · 1.10.658–660 · 관리자 없이 임원이 운영 시작 (정적 + functions)
- 요청: 게임 생성부터 대진 게시, 진행 중 코트 배정까지 임원에게 — 관리자 없이 운영.
- 조사: 엔진은 이미 임원에게 거의 열려 있었다. 벽은 둘이었다 — 운영 시작을 켜는 서버 명령이 없어 매치메이커가 대기표를 안 짰고, 진행 중 코트 등록은 명령은 있는데 임원 화면에 입구가 없었다.
- 새 명령 `official-operation-start`(게시 표시 + 즉시 보충 + 만료 연장). 임원 화면 「운영 준비」 패널(게시 전에만): 참가 등록 → 진행 중 코트 등록(4명 고르기 시트의 `kind:'court'`) → 대진 게시. 게시 전엔 마무리 도구를 숨긴다. 능력 표시 `officialOperationStartV1`.
- 실배포 E2E가 잡은 결함 둘: 관리자 재생이 코트 등록을 운영 시작으로 추론(659, `if(!match.transitionStarted)`), 관리자 라우팅 배열 누락(660).
- 첫 게시는 관리자가 한다. 무인 세션 생성은 만들지 않았다(초대 토큰이 세션 단위).

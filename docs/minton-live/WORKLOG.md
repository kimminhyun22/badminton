## 2026-09-15 · 1.10.668 · 방금 자동 투입된 배수 코트 즉시 닫기 (정적 + functions)
- 요청: 3코트를 자동 회전하던 중 방금 새 경기가 들어간 뒤 2코트로 줄이기로 한 현장 상황도 곧바로 처리할 것.

## 2026-09-15 · 1.10.667 · 진행 중 코트 수 유연 조정 (정적 + functions)
- 요청: 운동 중 피로도·참가 인원 변화에 맞춰 코트 수를 줄이거나 다시 늘릴 수 있게 할 것.
- 축소: 목표 코트 수는 즉시 바꾸되 초과 번호 코트의 진행 경기는 취소하지 않는다. 해당 코트에는 `종료 후 닫힘`을 표시하고 현재 경기 종료 뒤 새 경기를 넣지 않는다. 목표 범위 안의 코트는 계속 자동 회전한다.
- 증설: 대기 가능한 선수가 있으면 늘어난 빈 코트까지 서버가 즉시 자동 투입한다. 자동 다음 대진 수는 새 코트 수에 맞추고, 임원이 직접 편성한 대진은 축소해도 보존한다.
- 화면: 임원은 회원 링크의 `운영 현황 > 코트 N`, 관리자는 상황판의 코트 스테퍼에서 바꾼다. 관리자 진행 요약은 배수 중 `4→3`과 `4코트 종료 후 닫힘`으로 표시해 `4/3`처럼 보이지 않게 했다.
- 검증: 전체 `tests: 97/97 통과 · functions 문법 8개 · 실패 0 · 23s`. 4→3 배수 중 낮은 코트 재투입, 4코트 종료 뒤 미재투입, 3→4 즉시 투입, 직접 편성 보존, 두 임원의 오래된 동시 변경 거절을 확인했다. 자동 대기표 정리와 진행 중 축소 허용을 각각 제거한 훼손 시험도 실패했다.

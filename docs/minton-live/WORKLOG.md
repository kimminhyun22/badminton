## 2026-09-23 · 1.10.677–678 · 밴드 캡처 참가자 자동 등록 (정적)
- 요청: 참석 투표와 마감 뒤 댓글 신청 캡처 여러 장을 명부와 대조해, 회원·댓글 추가 회원·게스트를 일일이 체크하지 않고 등록할 것.
- 수정: `오늘 참가자 등록`에 `캡처로 등록`을 추가했다. 최대 8장을 브라우저 메모리에서 축소해 Firebase AI Logic으로 읽고, 앱이 이름 정규화·명부 정확 일치·겹친 캡처 중복 제거·댓글 추가·게스트·지각 상태를 확정한다. 원본 이미지는 저장하지 않는다. 명부에서 찾지 못한 이름은 자동 확정하지 않으며, 게스트의 급수·성별·연령을 최종 화면에서 확인한 뒤 한 번에 등록한다. 지각 댓글은 인원에서 빼지 않고 `도착 전` 상태로 등록한다.
- 안전성: AI는 글자를 읽는 역할만 맡고 집계와 등록은 결정 규칙으로 분리했다. 투표 댓글에서 게스트만 접수한 작성자는 참가자로 세지 않으며, 본인 참석을 명시한 댓글 작성자는 투표 밖 회원으로 더한다. 공개 AI 호출은 기존 reCAPTCHA Enterprise App Check를 다시 연결했다. 1.10.677 실배포 가명 시험에서 Gemini Developer API 선불 잔액 소진을 확인해, 별도 선불 충전 없이 기존 Firebase 프로젝트 Cloud Billing과 월 예산 통제를 쓰는 Agent Platform `global` 경로로 1.10.678에서 전환했다. 한도 오류의 내부 결제 문구는 짧은 재시도 안내로 바꿨다.

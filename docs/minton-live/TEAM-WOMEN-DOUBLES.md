# 팀전 여성별 여복 50% 우선 — v1.10.792

새 전체 대진 생성에 자동 적용한다. 혼복 횟수 입력은 없으며, 혼복 종목은 남는다.
기존 게시 대진·경기 결과·명부·실전 DB를 자동 변경하지 않는다.
부분 재배정은 기존 잠금/완료 경기 보존 경로를 사용한다. 이후 변경으로 여복 목표가 미달하면 품질점검에 표시한다.

## 후보 생성과 선택

- 여성별 목표는 인당 설정 게임의 절반을 올림한다. 실제 초과 출전이 있으면 실제 게임 수의 절반도 충족해야 한다.
- 양쪽 팀에 여성 2명 이상 있어야 여복이 가능하다. 고정 파트너를 해제하거나 기존 실력 안전 기준을 넓히지 않는다.
- 안전한 여성 2:2 조합을 제한된 빔 탐색으로 찾고, 여자 선수의 출전 슬롯을 여복에 먼저 확보한다. 기존 자동 종목 편성으로 나머지를 채운다.
- 기존 최적 대진 후보와 여복 우선 후보를 별도로 비교한다. 여복 후보 때문에 경기/라운드 수, 출전 미달·초과, 구조·종목 오류, 심한 균형 오류가 늘면 기존 후보를 유지한다.
- 채택 가능한 여복 후보 4개에 기존 일정 최적화와 공동 교환 최적화를 적용한다. 공동 최적화는 같은 팀 소속 선수의 경기 간 교환과 미달 선수 보충을 비교한다. 완료/무효 경기, 고정 파트너는 교환하지 않는다.
- 공동 최적화는 최대 6회 × 48개 품질 평가. 확보한 개인별 여복 목표, 출전·실력 안전 검사, v4 점수·평균 파트너 보정 격차·연속 출전 보호를 통과해야 채택한다. 실패하면 여복 예약 후보로 복원한다.
- 안전한 후보 중 여성 목표 충족 인원을 우선하고, 같으면 기존 v4 품질점수를 비교한다. 종목 선호를 점수에 덧붙여 균형점수를 부풀리지 않는다.

## 화면과 한계

품질점검에 `여복 50% 우선` 행을 추가한다. 목표 충족 인원, 여성별 여복/전체 게임과 목표를 보여준다. 미달은 주의사항에도 표시한다.

여성이 4명 미만이거나 한 팀에 2명 미만, 고정 혼복 파트너, 안전한 실력 조합 부족, 출전/일정 제약에서는 목표를 보장하지 않는다. 제한 탐색의 미달이 수학적 불가능을 증명하는 것은 아니다. 일반 자유대진에는 이 팀전 정책을 강제하지 않는다.

기존 15개 사례·45개 최종 실험 대진 검증은 격리 v790 실험이었다. 이번 릴리스는 v791 코드에 통합한 생성·저장·복원 경로를 다시 검증한다. 공개 테스트는 가명과 격리 브라우저를 사용하고 백엔드 연결을 차단한다.

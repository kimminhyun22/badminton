# 실력 기준 점검

최종 갱신: 2026-09-26 · v1.10.728

- 보정 검토 준비율: 비교 가능한 상대가3명 이상인 회원 중 서로 다른 상대3명 이상·의견 충돌 없음·서버 적용 검토 가능 또는 변경 제안 없음인 회원의 비율. 정수 내림으로 미완료를100%로 반올림하지 않는다. 명부 적용률/실력 정확도/통계적 신뢰도가 아니며 새 의견에 따라 낮아질 수 있다. 상대 부족 회원은 제외 인원을 명시하고 개별 목록에 남긴다. 모두 부족하면 백분율 대신 부족 상태 표시. 최소 추가 문항은 회원별3명까지 부족한 비교 수 합계/2의 올림인 하한이며 방향 합의/선택된 문항에 따라 실제 필요 수는 늘어난다.

- 관리자 기본 흐름: 명부 선택 → 밸런스게임 준비 → 준비 완료/공유 버튼 → 응답 결과. quick/분기 알림·기존 퀴즈 재사용도 관리자 준비 화면에 머문다. 직접 참여는 '나도 참여하기'를 눌렀을 때만 시작한다. 공유 토큰 준비 실패에는 재시도, 마감에는 공유 비활성화. 응답 전 빈 결과표는 숨긴다.

- 질문은 '반드시 이겨야 하는 게임, 누구와 파트너를 하시겠어요?'로 통일. 진행 중 격려/보조 설명을 제거하고 진행률·질문·선택만 표시한다. 공유 제목/미리보기 서비스명은 민턴라이브이며 새 공유 URL에 앱 버전을 붙인다. 과거 메신저 미리보기 캐시는 앱에서 직접 지울 수 없다.

- 대결 카드·응답 진행 막대·짧은 전환과 참여 기여 문구를 사용한다. 정답/속도/순위 보상은 없다. 동작 줄이기 설정에서는 애니메이션을 생략한다. 완료 요약의 비교 수와 고유 회원 수는 건너뛴 답을 제외하며, 진행 막대는 건너뛰기도 완료로 센다. 질문 선정·점수·적용 기준은 그대로다. 응답률 개선 효과는 아직 실사용 검증 전이다.

- 비슷함도 주요 선택으로 크게 표시한다. 이전 문항으로 이동하면 선택한 답이 강조된다. 마지막 답변 뒤 응답 저장을 눌러야 전송되며 저장 후 '방금 응답 수정'으로 교체 가능. 응답 수정은 명부에 이미 저장한 보정을 자동 취소하지 않는다.

## 결과 읽기

- 응답 저장은 적용 완료가 아니다. 결과 상단에 반영 완료/적용 가능/추가 확인/변경 제안 없음과 미비교 인원을 분리한다.
- 개인별 점수는 기본 실효점수+개인 보정으로 표시. 예:3.5→3.7(+0.2). 원래 급수·연령·성별 기준은 바꾸지 않는다.
- 상대별 응답의 합의 방향을 펼쳐 검토한다. 추가 확인에는 상대 수 부족/조정 방향 부족/판단 충돌 이유를 표시한다. 기준 유지도 실력 확정을 뜻하지 않는다.
- 반영 완료는 현재 기기의 명부가 제안과 같은지 확인한 상태다. 다른 기기 명부까지 동기화됐다는 보장은 아니다. 현재 프로필이 바뀌면 기존 제안은 적용하지 못한다. 이미 생성된 대진은 재배정하지 않는다.

- 진입 시 회원별 급수·성별·연령·보정값 검증. 빈 연령은 기존 명부/대진 엔진과 동일한40대 기본값을 사용하고 화면에 명시한다. 그 외 잘못된 정보는 목록으로 표시하며 운영자가 확인하면 정상 회원만으로 시작할 수 있다. 원본 명부는 그대로 유지한다. 중복 이름은 양쪽 모두 확인 대상으로 둔다.

## 분기 재점검

- 처음 유효한 5개 응답을 마친 서버 시각을 점검일로 기록한다(비교 후보가 5개 미만이면 전부). 건너뛰기·재전송·페이지 열기로 연장하지 않는다.
- 90일 경과 시 민턴/팀전 관리자 상단에 클럽별 알림. 누르면 해당 클럽의 연속 비교에 바로 진입한다. 기존 개인 보정값을 기준으로 재점검한다.
- 보정안은 즉시 계산하며 충분한 일관성이 있으면 기존 명부 저장 확인으로 적용한다. 5문제만으로 모든 회원의 보정이 확정된다고 보장하지 않는다.
- 알림은 앱 내 표시이며 OS 푸시가 아니다. 점검일은 서버 조회/응답 시 만든 기기에 보관하므로 서버 설문 정리 후에도 유지된다. 기기 저장 삭제·다른 기기에서는 보장되지 않는다. 구버전 또는 응답 완료를 수신하지 못한 기록은 생성일을 보수적 재점검 기준으로 사용한다.

## 현재: 우리 클럽 밸런스게임

- 단톡방 공용 링크 → 본인 이름 선택 → 응답. 서버 share는 만든 기기만 실행하고 join은 공용 토큰으로 명부 내 ID를 선택한다. 개인 응답 토큰은 브라우저에 보관하며 서버에는 해시만 저장. 같은 이름의 타 기기 선점/덮어쓰기와 한 토큰의 다중 이름을 거절하고 개인별 표수/수정 이력을 분리한다. 본인 인증은 아니므로 신뢰하는 임원방에만 공유한다. 첫 참여 브라우저 저장소를 잃으면 현재는 직접 복구할 수 없다.

운영자 요청으로 범위를 개인 보정에 한정했다. 급수·연령·성별 기본 계수는 그대로 두며, 파트너 격차·인구집단 계수 설문은 현행 화면에서 제거했다. 아래 v715 절은 이전 실험 기록이다.

- 클럽 명부 선택 → 퀴즈 만들기 → 단톡방 링크 공유 → 본인 이름 선택 → 좌우 선수 카드 직접 선택. 5개마다 끊지 않고 비교 후보가 적으면 전부, 많으면 최대20개 연속 진행한다. 추가 비교는 선택 사항이다. 비교 횟수가 적은 회원부터 고르게 선정하며, 한 차례로 전체 회원의 보정을 보장하지 않는다.
- 중간 응답과 문제 순서를 기기에 저장해 재접속 시 이어간다. 전송은 서버 제한대로 최대5개씩 나누지만 완료 화면은 한 번만 표시한다. 부분 전송 실패 시 성공분을 제외한 나머지만 재시도한다.
- 같은 급수 중 기본 실효 차이가 0.7 이내인 회원을 비교한다. 이름·급수·성별·연령만 응답자에게 보이며 점수·개인 보정·타인의 응답·관리자 키는 보이지 않는다.
- 이전 개별 링크 e0/e1/e2와 응답은 보존한다. 새 이름별 응답 u_pN과 함께 집계되며 이전 익명 응답을 특정 이름으로 추정/이관하지 않는다. 이전 응답이 있으면 결과에 중복 참여 주의 문구를 표시한다. 이미 참여한 사람은 이전 링크에서 수정하고 새 링크로 다시 참여하지 않는다.
- 세션의 고정 명부를 기준으로 상대 비교 제약을 최소 변경 방식으로 맞춘다. 현재 연령·성별로 이미 설명되는 우세는 추가 가산하지 않는다. ±0.4 범위 내 5단계의 **임시 보정안**만 서버에서 계산한다.
- 해당 선수의 서로 다른 비교 상대3명 이상에서 같은 조정 방향80% 이상, 응답자 간 항목 충돌 없음이면 **적용 검토**. 이는 통계적 유의성/실제 승률 보장이 아닌 운영 검토 기준이다. 비교 상대가 적은 선수는 수동 명부 보정을 유지한다.
- 알림은 앱 내부다. 미세조정 화면과 관리자 앱이 보이는 동안60초 간격, 앱 복귀 시 확인한다. 앱을 닫아도 응답은 서버에 쌓이나 OS 푸시·메일 발송은 없다. 최근3개 퀴즈를 관리자 앱에서 확인한다.
- 적용 확인은 기존 명부 회원 편집창에 제안값을 채우는 방식이다. 수정 저장 전 실제 데이터는 그대로다. 현재 명부와 퀴즈 원본이 다르거나 요청이24시간 지났으면 적용창 진입을 막는다. 기존 명부 저장·전파 경로를 재사용한다.

## 데이터 경계

시험 화면은 명부를 읽기만 한다. 선수 선택 후 항목을 바꿔도 원본·대진·Firebase에는 쓰지 않는다. 연령/성별 강도는 화면 메모리에만 있으며 새로고침하면 100%로 돌아온다. 음수 점수도 기존 계산값을 그대로 보여준다.

개인 보정이 이미 저장된 `level`은 다시 가산하지 않는다. 급수·성별·연령이 없는 프로필은 확인 대상으로 표시한다. 명부 편집은 기존 명부 편집 화면의 5단계를 그대로 쓴다.

설문은 익명 기기 식별자·조사명·문항 ID·선택 값만 저장/내보낸다. 선수 이름은 내보내지 않는다. 다른 조사명, 미래 정책, 잘못된 값은 거절한다. 같은 응답 파일은 한 번만 집계하고 동일 기기의 충돌 답변은 기존값을 덮지 않는다. 합치기 도중 한 파일이라도 실패하면 전체를 저장하지 않는다. 같은 사람이 여러 기기를 사용했는지는 인증하지 않으므로 실명 기반 고유 응답자 통계가 아니다.

5명/70%는 화면의 검토 분류 기준이지 통계적 유의성 기준이 아니다. 파일 집계는 이 기기에만 저장되며 서버 자동 취합이나 배포용 설문 링크를 제공하지 않는다. 클럽별 조사명을 사용한다.

## 다음 행동과 완료 기준

1. 운영진이 점수와 복식 파트너 격차를 비교해 설명 가능한지 확인한다.
2. 조사별 응답 분포를 보고 의견이 모이는 조건만 계수 변경 후보로 삼는다. 표본 부족·의견 분산은 기존 기준을 유지한다.
3. 운영 계수를 바꾸기 전 서버/브라우저 단일 배포 원본, 급수 역변환 호환성, 원본 프로필 보존과 세션 정책 버전을 먼저 구현한다.
4. 같은 시드·명단으로 팀 실력차, 파트너 격차, 출전 기회, 반복 조합의 전후 분포를 확인한 뒤 새 행사부터 제한적으로 적용한다.

현재 배포의 완료 기준은 비교·설문·중복 방지·원본 불변성·모바일 표시 검증이다. 실전 예측 정확도와 새 계수 도입은 완료로 판정하지 않는다.

# 실력 기준 점검

최종 갱신: 2026-09-24 · v1.10.715

## 목표와 현재 위치

운영자가 급수·성별·연령·개인 보정의 영향을 같은 눈금으로 비교하고, 운영 경험을 모아 검토할 근거를 만든다. 회원의 추가 입력이나 경기 결과 수집은 요구하지 않는다.

- 구현: 민턴·팀전 명부의 「실력 기준 점검」 공통 입구, 선수 2명/복식 2팀 비교, 점수 구성, 파트너 격차, 시험 보정 강도.
- 구현: 14개 익명 조건 비교 질문, 응답별 좌우 교차, 조사명별 기기 응답 저장, 파일 내보내기/합치기, 중복 제거·충돌 거절.
- 구현: 공용 브라우저 평가 모듈에 현행 `skill-v1`의 읽기 전용 기준과 점수 분해 함수. 서버와 동일한 600조건 회귀 검사.
- 미적용: 운영 계수 변경, 서버 코드 통합, 과거 급수 역변환 수정, 행사별 계산 정책 고정·이관. 현재 계수를 그대로 유지하므로 이번 배포로 진행 경기의 실력 계산은 바뀌지 않는다.
- 실사용 검증: 운영진 설문과 판단 정확도 확인 대기. 코드 검사는 실력 예측의 정확성을 증명하지 않는다.

## 데이터 경계

시험 화면은 명부를 읽기만 한다. 선수 선택 후 항목을 바꿔도 원본·대진·Firebase에는 쓰지 않는다. 연령/성별 강도는 화면 메모리에만 있으며 새로고침하면 100%로 돌아온다. 음수 점수도 기존 계산값을 그대로 보여준다.

개인 보정이 이미 저장된 `level`은 다시 가산하지 않는다. 급수·성별·연령이 없는 프로필은 확인 대상으로 표시한다. 명부 편집은 기존 명부 편집 화면의 5단계를 그대로 쓴다.

설문은 익명 기기 식별자·조사명·문항 ID·선택 값만 저장/내보낸다. 선수 이름은 내보내지 않는다. 다른 조사명, 미래 정책, 잘못된 값은 거절한다. 같은 응답 파일은 한 번만 집계하고 동일 기기의 충돌 답변은 기존값을 덮지 않는다. 합치기 도중 한 파일이라도 실패하면 전체를 저장하지 않는다. 같은 사람이 여러 기기를 사용했는지는 인증하지 않으므로 실명 기반 고유 응답자 통계가 아니다.

5명/70%는 화면의 검토 분류 기준이지 통계적 유의성 기준이 아니다. 파일 집계는 이 기기에만 저장되며 서버 자동 취합이나 배포용 설문 링크를 제공하지 않는다. 클럽별 조사명을 사용한다.

## 다음 행동과 완료 기준

1. 운영진이 점수와 복식 파트너 격차를 비교해 설명 가능한지 확인한다.
2. 조사별 응답 분포를 보고 의견이 모이는 조건만 계수 변경 후보로 삼는다. 표본 부족·의견 분산은 기존 기준을 유지한다.
3. 운영 계수를 바꾸기 전 서버/브라우저 단일 배포 원본, 급수 역변환 호환성, 원본 프로필 보존과 세션 정책 버전을 먼저 구현한다.
4. 같은 시드·명단으로 팀 실력차, 파트너 격차, 출전 기회, 반복 조합의 전후 분포를 확인한 뒤 새 행사부터 제한적으로 적용한다.

현재 배포의 완료 기준은 비교·설문·중복 방지·원본 불변성·모바일 표시 검증이다. 실전 예측 정확도와 새 계수 도입은 완료로 판정하지 않는다.

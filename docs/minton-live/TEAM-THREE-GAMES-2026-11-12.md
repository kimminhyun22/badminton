# 3경기 팀전 탐색·여복 보완 — v1.10.807

## 요청과 확인

팀전 신청자 평가 후 4코트·인당 3경기를 진행할 때, 현재 구성원으로 경기 격차를 줄이고 청·홍 우세를 고루 배분하도록 점검했다. 개인 점수는 기존 클럽 평가에서 출발하며 이번 신청자 평가의 새 답변을 확인한 뒤 공식 명부에 적용한다.

공개 코드 v806의 3경기는 기본 생성과 여복 우선 계획은 지원했지만, 명시적 팀 재배정의 전체 경기 비교·기존 대진의 읽기 비교·여복 부족 복구·조건부 여복 완화가 4경기로 제한돼 있었다. 기존 회귀와 별개로 같은 익명 27명(남15/여12)·4코트·3경기에서 시드71/227·180후보씩 재검증했다. 각 21경기·6라운드·전원3~4회·불가피 추가3회·필수 위반0이었으나 여성4명이 여복0회였다. 이는 저장된 실제 경기표의 감사가 아니라 같은 명단과 현재 점수로 새로 생성한 격리 모의 결과다. 실제 브라우저는 최소90후보 이후 시간·정체 기준 탐색이므로 고정180후보 시험과 예산이 다를 수 있다.

## 구현과 보호

- 명시적 **팀 재배정·현재 대진 비교**를 인당3~4경기·40명 이하로 확대한다. 실제 진행·완료 경기는 기존 차단을 유지하고, 읽기 비교는 선수와 경기표를 바꾸지 않는다. 최초 자동 팀 배정은 기존 경로다. 작은 미리보기만으로 이미 안전한 완성안을 바꾸지 않는다.
- **3경기 여복 복구**를 연결한다. 여복0회 감소를 먼저 탐색하고 가능한 경우50% 목표를 보완한다. 3경기의50% 이상은2회(약67%)이며 항상 가능한 횟수라는 보장은 아니다.
- 최종 복구안은 최초 원본과 현재 입력안 모두에 대해 경기 접전 항목·평균/최악20%/최대 보정격차·전체 순격차 절댓값·접전을 제외한 우세 수 차를 악화시키지 않는다. 출전 횟수, 경고, 개인별 출전/휴식 라운드, 상대/파트너 반복도 기존 보호를 유지한다.
- 고립된 사본의 유한 탐색에서는 중간 교환을 허용하지만, 최종 채택에서 위 엄격 검사를 다시 한다. 중간안을 운영 화면이나 서버에 적용하지 않는다. 접전의 수치 경계0.20을 넘나드는 경기 수는 원본보다 최대2개 줄 수 있다. 이는 접전 **개수** 무조건 보존 정책이 아니다.
- 새3경기 생성의 최초 복구 기준은 중간 폐기안이 아니라 실제 보존된 완성안이다. 기존 `womenRecoveryOrigin`이 있으면 재사용한다. 반복 재배정·저장/복원으로 기준을 다시 정하지 않는다. 4경기의 기존 정책은 유지한다.
- 3경기에서도 기존 **여복 목표 조건부 완화**를 비교한다. 최대격차0.10 및10% 이상 감소·여성별 최소1회 보존·평균/꼬리/순격차·반복/휴식 보호를 유지하며, 3경기에는 경기 항목 점수와 우세 수 차 비악화도 확인한다.
- 입력 점수·명부·현재 게시 대진은 자동으로 고치지 않는다. 새 평가를 적용한 뒤 새 생성/명시적 재배정에서 사용한다.

## 품질점수 기준표 동시 검토

품질 **scoreVersion10**의 산식·배점·등급은 유지한다. 접전55/우세20/여복10/다양성5/휴식10이며, 가능한 여복이 전혀 없으면 접전65다. 전원 출전은 필수 조건이다. 동일한 완성 대진 3개를 이전 평가 함수와 대조해 평가 JSON·후보 순위가 동일함을 확인했다. 배점을 낮추거나 점수만 올린 변경이 아니다.

이번 변경은 적용 가능한 후보와 보호 조건을 넓히므로 **비교기록 version4**로 구분한다. 관리자와 임원 화면 모두 옛v3 후보 비교는 만료한다. 기존에 저장한 절대 품질점수는 보존한다. 합계는 정책 항목의 합이며 실제 승률·전역 최적 달성률·모든 수동 편성 대비 우수성을 뜻하지 않는다.

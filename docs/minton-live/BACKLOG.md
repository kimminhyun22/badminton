# 민턴LIVE 남은 일

## 운영자 확인이 필요한 것 (먼저 묻는다)
1. **회원 자가 도착** — 롤오버 뒤 회원이 본인 화면에서 도착을 누르게 할지. 「운영 흐름은 회원 입력에 의존하지 않는다」「늦게 오면 임원이 참가 등록」(DECISIONS 상시·2026-08-11)과 맞물려 보류 중.
2. **일시정지·재개, 자동대진·운영 시간을 임원에게 열지** — 지금은 이를 위한 서버 명령이 없다(`official-settings-update` 는 코트 수만 받는다). 열려면 새 명령 + 여섯 곳(PITFALLS 1) + 능력 표시가 필요하다.
3. **디자인 브랜치 `codex/design-refresh`** — 2026-09-02 디자인 작업 2커밋. main 보다 27커밋 뒤처졌고, 브리프가 병합 금지로 지정했다. 버릴지 다시 할지 결정 대기.
4. **성별 격차 1.5** — `gradeToLevel` 의 여성 −1 과 실효 −0.5 가 겹친다. 한 상수로 모으고 하한을 둘지(운영자: "우리 클럽 최저는 D조"). 팀전과 공용이라 영향이 크다.

## 바로 해도 되는 것 (권장 순서)
1. **임원 화면 일괄 도착 등록** — 롤오버 뒤 전원이 도착 전이라 임원이 한 명씩 참가를 누른다(20명이면 20번). 관리자 화면의 「전체 선택 → 현장 참가 등록」처럼 여러 명을 한 번에. 새 서버 명령으로 할지, 기존 도착 명령을 여러 번 보낼지는 설계 판단이다. 여러 번이면 부분 실패 표시와 관리자 추종(리비전이 한 번에 여러 개 오른다)을 실배포로 확인한다.
2. **민턴LIVE 관리자 「임원 화면 열기」 버튼** — 팀전 관리자에는 있다(`liveConsoleTopBtn`). `js/daily.js` 에 `checkin.html?official=` 빌더는 있는데 여는 버튼이 없다. 팀전과 같은 자리·같은 문구로.
3. **관리자 재검사가 서버 적용분을 거절하면 영구 정지하는 구조** — 서버가 이미 적용한 명령은 관리자가 거절 대신 채택으로 넘어가게. 추종자의 핵심이라 감리 대상.
4. 롤오버 직후 「새 링크가 필요합니다」 순간 표시(PITFALLS 11) — 재현되면 빈 스냅샷일 때 판정 보류.
5. PWA를 켜 둔 채 임원 연결(grant)이 만료되면 「다시 연결」을 손으로 눌러야 한다 — 자동 재연결.
6. 도착 전(planned) 상태 임원의 연결 해제 문구 다듬기.
7. 롤오버 되돌리기 — 지금은 게시 4시간·진행 코트 0·대기표 0·확인창으로만 막는다. 필요성 낮음.

# 사용량과 보정 정보

## 사용량
- 방문·링크 생성·운동 종료 버튼 대신 경기 완료 기록을 센다.
- 민턴LIVE: 완료 누계와 완료 기록. 같은 운동의 보관본·보관 대기는 중복 제외.
- 팀전: 승패가 남은 경기. 승패 정정은 추가 집계하지 않고 취소·미실시는 제외.
- 한 경기 이상 완료한 운동만 사용 세션으로 센다. 클럽명만으로 클럽 수를 추정하지 않는다.
- 개발 운영자가 `node tools/usage-report.js --firebase`로 조회한다. 기존 Firebase CLI 인증을 사용하며 데이터 쓰기는 없다. 결과에는 회원명·평가자·공유 키가 없다.
- 현재 보관된 기록의 조회이지 전체 누적 통계나 상시 수집이 아니다. 이미 만료·삭제된 기록은 복원하지 않는다. 두 경로 조회 중 운영이 바뀔 수 있으므로 정확한 마감 집계에는 운영 후 다시 조회한다.
- 별도 분석 SDK·방문 추적·자동 종료는 추가하지 않는다. 조회에는 기존 Firebase 데이터 읽기 비용이 적용된다.

## 보정 정보
- 기존 설문을 만든 기기의 운영자 키로 개인 보정안·반영 상태·집계 근거를 본다.
- 일반 응답 링크에는 개인 점수·보정안·다른 사람의 응답을 제공하지 않는다. 응답자는 본인 답만 수정한다.
- 운영자 결과에도 누가 누구를 평가했는지는 표시하지 않는다. 일반 회원 화면에 개인 보정 순위·평가 결과를 추가하지 않는다.
- 이는 익명 설문이라는 뜻은 아니다. 서버에는 중복 방지용 응답자 연결 정보가 있다. 운영자 키나 명부 백업 파일을 일반 회원에게 공유하지 않는다.
- 운영용 명부·대진 데이터의 계산값까지 기술적으로 비공개화한 것은 아니다. 공개 화면에서 비교하지 않는 현재 운영 원칙을 유지하며 인증·DB 규칙은 이번에 변경하지 않는다.

# 콕매치 클럽 자율 배포 로드맵

현재 진행 현황은 [시각화 현황판](ROADMAP.html)에서 확인한다. 갱신 원본은 `roadmap.json`이며 이 문서는 2026-09-17 계획 기준선이다.

기준일: 2026-09-17. 현재 `main`의 민턴LIVE·팀전LIVE 구조와 실배포 검증 기록을 기준으로 작성했다. 구현·테스트·배포·실사용 검증을 구분하며 근거 없는 완료율은 표시하지 않는다.

## 최종 목표

각 클럽과 정기모임이 중앙 시스템 관리자의 설정 없이 독립 공간을 만들고, 하나의 명부와 영구 링크로 자유운동과 팀전을 반복 운영한다. 회원은 가입 없이 자기 경기만 확인하고, 클럽 임원은 같은 링크에서 당일 운영을 처리한다.

## 관찰 가능한 완료 기준

- 처음 온 운영자가 도움 없이 5분 안에 클럽 공간과 영구 링크를 만든다.
- 30명 안팎의 명단을 붙여넣어 10분 안에 첫 운동을 시작한다.
- 다음 정기운동은 기존 명부로 1분 안에 연다.
- 민턴LIVE와 팀전LIVE가 같은 클럽 명부를 사용하며 중복 입력이 없다.
- 회원은 별도 가입 없이 같은 클럽 링크에서 이름 확인 후 현재·다음 경기를 본다.
- 대표 기기를 잃어도 운영 권한과 명부를 다른 기기에서 복구한다.
- 서로 다른 클럽은 상대 명부·운동·운영 권한을 읽거나 바꿀 수 없다.
- 파일럿 3개 클럽이 각 3회 이상 중앙 관리자 개입 없이 운영한다.
- 공개 생성 남용, 비정상 요청, 장기 미사용 데이터와 비용 증가를 제한한다.

## 현재 확보한 기반

- 민턴LIVE는 정식 임원이 당일 명부 등록부터 코트·대진 게시·진행·다음 운동일까지 운영한다.
- 팀전LIVE는 청홍팀전과 자유대진, 승패 입력, 임원·도우미 운영을 지원한다.
- 회원은 같은 링크에서 본인 확인 후 경기 현황을 보고, 스마트폰이 없어도 임원 안내로 참여할 수 있다.
- 서버 명령은 지문 대조와 트랜잭션으로 동시 조작을 처리하며 실배포 E2E 절차가 있다.
- 다만 최초 클럽 명부·상시 링크는 시스템 관리자 브라우저에서 만들어야 하고, 관리자 원본 일부가 localStorage에 묶여 있다.

## 우선순위 판단

새 화면보다 데이터 격리와 복구를 먼저 한다. 현재 앱을 그대로 공개하면 각 클럽의 최초 링크 생성과 관리자 원본 복구를 중앙 운영자가 계속 맡게 되므로 목표를 달성하지 못한다. 반대로 로그인·결제·공개 클럽 검색부터 만들면 진입 장벽과 운영 비용만 늘어난다.

## 공개 범위에서 제외

- 회원 의무 가입
- 공개 클럽 검색·랭킹
- 결제·광고
- 채팅·카카오 자동 초대
- AI를 대진 진행의 필수 경로로 사용하는 기능
- 네이티브 앱 선행 개발

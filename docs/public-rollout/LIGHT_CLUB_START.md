# 클럽에서 민턴LIVE 시작하기

운영자용 주소: https://kimminhyun22.github.io/badminton/

앱 안의 **설명서 → 설치·사용 안내 공유**에서 카톡을 선택하거나 **안내 복사**를 누릅니다. 운영자에게 보낼 [카톡용 짧은 안내](KAKAO_START.txt)와 [설명서 바로가기](https://kimminhyun22.github.io/badminton/?manual=1)를 준비했습니다. 자동 발송하지 않으며 대상 대화방은 직접 선택합니다.

## 설치 (선택)
- iPhone/iPad: Safari에서 운영자용 주소 → 공유 → 홈 화면에 추가. 웹 앱으로 열기 옵션이 보이면 켭니다.
- Android: Chrome에서 운영자용 주소 → 메뉴 → 홈 화면에 추가 또는 앱 설치.
- 카톡 안에서 설치 메뉴가 없으면 주소를 복사해 Safari/Chrome에서 엽니다.
- 실제로 사용할 홈 화면 앱을 먼저 설치하고, 그 앱 안에서 명부를 등록합니다. 회원은 설치 없이 운동 링크만 열어도 됩니다.
- 설치 메뉴는 OS·브라우저 버전에 따라 다릅니다. [Apple 안내](https://support.apple.com/guide/iphone/turn-a-website-into-an-app-iph42ab2f3a7/ios), [Chrome 안내](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ko).

## 처음 시작
밴드 멤버 목록이 있다면 **명부 → 캡처로 명부 만들기**를 사용합니다. 새 명부 또는 추가할 기존 명부를 고르고 최대 8장씩 읽습니다. 중복 캡처는 합치고, 기존 회원의 정보는 유지합니다. 성별·급수·연령의 빈칸과 읽은 이름을 수정한 뒤 **명부 저장**을 누릅니다. 화면 총원과 읽은 인원이 다르면 나머지 캡처를 추가하세요. 사진으로 성별을 추측하지 않습니다. AI 인식에는 오류가 있을 수 있어 저장 전 확인이 필요합니다.

1. 명부 → **명부 만들기**에서 클럽명과 회원을 등록합니다. 가입이나 대표 지정은 필요 없습니다.
2. 명부에서 참가자를 선택하고 민턴LIVE 또는 팀전으로 진행합니다.
3. 대진 게시 후 **공유하기**로 운동 링크를 회원에게 보냅니다. 운영자용 앱 주소와 회원 운동 링크는 다릅니다.

## 다음 운영진에게 전달
1. 명부 → **명부 전달**에서 전달할 클럽을 선택합니다.
2. **공유하기** 또는 **파일 저장**으로 JSON 명부 파일을 전달합니다. 공유 대상은 기기에서 지원하는 앱에 따라 다릅니다.
3. 받는 사람은 앱의 명부 → **명부 받기**에서 파일을 선택합니다.
4. 회원·개인 실력 보정을 확인하고 **이번 운영 임원**을 선택한 뒤 저장합니다.
5. 새 운동을 시작하고 새 회원 링크를 공유합니다.

같은 이름의 명부가 있어도 합치거나 덮어쓰지 않습니다. 이름·성별·연령·급수·개인 보정값은 전달하지만 이전 계정, 로그인 정보, 운동 기록, 임시 운영 권한은 전달하지 않습니다. 설문 원본과 이전 설문 링크도 포함하지 않습니다.

전달 후 두 명부는 독립된 사본으로, 한쪽 수정이 다른 쪽에 자동 반영되지 않습니다. 기존 경기의 운영권을 넘기는 기능이 아닙니다.

## 선택 사항
- **서버 저장 연결**: 원하는 운영자만 Google 계정으로 명부를 보관합니다. 전달받은 새 명부도 별도로 연결할 수 있습니다.
- 파일에는 회원 정보가 있으므로 다음 운영진에게만 전달하고 공개 게시하지 않습니다.
- iPhone에서 파일 공유 대상이 나타나지 않으면 파일 저장 후 전달합니다. 홈 화면 앱과 Safari의 저장소가 다를 수 있으므로 실제 운영할 앱에서 명부를 받습니다.

## 제한 파일럿
2~3개 클럽에서 먼저 시작 흐름과 운영을 확인합니다. 새 명부 전달은 다중 클럽 보안 개편 완료를 뜻하지 않습니다. 현재 운동 링크·이름 확인 기반 운영의 신뢰 경계와 공개 남용 방지는 별도 검증 대상입니다.
